# TACMAP (Tactical Air Situation Consensus Engine & Map)

[![Rust](https://img.shields.io/badge/Language-Rust_1.80+-orange.svg?style=flat-square&logo=rust)](https://www.rust-lang.org/)
[![MapLibre](https://img.shields.io/badge/Frontend-MapLibre_GL-blue.svg?style=flat-square)](https://maplibre.org/)
[![Status](https://img.shields.io/badge/Status-Completed_%26_Archived-emerald.svg?style=flat-square)]()
[![Author](https://img.shields.io/badge/Telegram-@nestor__churin-24A1DE.svg?style=flat-square&logo=telegram)](https://t.me/nestor_churin)

**TACMAP** — це високопродуктивний тактичний рушій консенсус-кластерингу, супроводу повітряних об'єктів та векторної візуалізації в реальному часі (Rust + MapLibre GL). 

Проєкт створювався як волонтерський технічний R&D-експеримент для дослідження швидкої консолідації різнорідних джерел спостереження повітряного простору, усунення телепортацій/помилок радарів та об'єктивного математичного оцінювання точності агрегаторів.

> [!NOTE]
> **Статус проєкту (Жовтень 2026): МІСІЮ ВИКОНАНО.**  
> Офіційні державні платформи та моніторингові мапи повністю реалізували необхідні функції відображення повітряних загроз у реальному часі. Проєкт TACMAP успішно завершив свою роботу і переведений у публічний архів як приклад інженерної архітектури.

## 🏛 Архітектурний пайплайн

```
[ Джерела / Потоки ] (REST / WebSocket / Telegram OSINT)
         │
         ▼
[ Рубіж 1: Bounding Box & Theater Filter ] (Фільтрація координат за межами театру 42–56°N, 20–46°E)
         │
         ▼
[ Рубіж 1.5: Track Deduplication ] (Усунення клонів та фрагментів треків одного джерела)
         │
         ▼
[ Рубіж 2: Speed-Gate & Memory Tracker ] (Відсікання фізично неможливих стрибків > 2000–25000 км/год)
         │
         ▼
[ Рубіж 2.5: Consensus Clustering ] (Complete Linkage злиття з урахуванням розбіжності курсів та типів)
         │
         ▼
[ Рубіж 3: Target Tracker & Corridors ] (Присвоєння стабільних ID, хвости за годину, розрахунок ETA підльоту)
         │
         ▼
[ Delivery: Axum GeoJSON & WebSocket ] ──► [ Frontend: AMOLED MapLibre GL (60 FPS) ]
```

## 🚀 Ключові технологічні особливості

### 1. Консенсус-кластеринг (`backend/src/cluster.rs`)
* **Алгоритм Complete Linkage:** якщо різні радари фіксують одну й ту саму ціль з невеликим просторовим зміщенням, алгоритм попарно оцінює сумісність типів та різницю векторів руху (курсу).
* **Speed-Gate та фізичні обмеження:** автоматично відсікає помилкові «стрибки» і засічки, неможливі для аеродинамічних характеристик відповідного типу загрози (БпЛА, крилаті ракети, балістика, тактична авіація).
* **Стабільне хешування ID:** ідентифікатор кластера залишається постійним між циклами опитування, запобігаючи мерехтінню міток на карті.

### 2. Модуль оцінки точності радарів (`backend/src/accuracy.rs`)
Проєкт містить повноцінну аналітичну систему для порівняння якості даних різних джерел:
* Збереження історії спостережень у локальній базі **SQLite (WAL mode)**;
* Розрахунок метрик: **Precision** (точність), **Recall** (повнота охоплення), **Spatial Accuracy** (просторове відхилення в км) та **Stability**;
* Звірка засічок із офіційними сповіщеннями ПС ЗСУ та статусами повітряних тривог.
* Детальний математичний опис наведено у [docs/ACCURACY.md](docs/ACCURACY.md).

### 3. Евристика пусків та коридори підльоту (`backend/src/launches.rs`, `approach.rs`)
* База відомих точок базування стратегічної та тактичної авіації, пускових районів БпЛА та флотських позицій (~19 точок);
* Побудова геодезичних коридорів підльоту до державного кордону України з живим динамічним розрахунком часу підльоту (ETA) для кожного типу носія.

### 4. Надшвидкий AMOLED-фронтенд (`frontend/`)
* Оптимізований під нічний тактичний режим (чистий чорний фон `#000000`, векторні тайли OpenFreeMap, мінімальне навантаження на акумулятор мобільних пристроїв);
* Рендеринг виключно через пакетні GeoJSON-шари (`setData`), без створення окремих важких DOM-маркерів;
* Повна PWA-підтримка та офлайн-кешування статики.

## 🛠 Технологічний стек

* **Backend:** Rust 1.80+, Axum 0.7, Tokio (Multi-threaded async runtime), Rusqlite, Serde JSON, Futures.
* **Frontend:** Vanilla JavaScript (ES2022+), MapLibre GL JS, CSS AMOLED Variables.
* **DevOps:** Nginx (Rate limiting, WebSocket upgrade, Gzip, Security Headers), Systemd, Debian LXC / Proxmox.

## 💻 Локальний запуск для ознайомлення

Встановіть Rust toolchain (`cargo`), після чого:

```bash
# Клонування репозиторію
git clone https://github.com/nestorchurin/tacmap.git
cd tacmap

# Запуск бекенду
cd backend
cargo run --release
```

Веб-інтерфейс буде доступний за адресою: `http://localhost:8080/`  
Запуск тестів (86 unit-тестів алгоритмів кластерингу, геодезії та трекера):
```bash
cargo test
```
